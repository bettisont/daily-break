# Skills

Copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `abeeaf9` (MIT, see
`LICENSE-mattpocock-skills`). These are plain editable copies: adapt them freely; to update, re-copy from upstream.

- `/grill-me`: interview you relentlessly about a plan (uses `grilling`).
- `/grill-with-docs`: the same, but writes `GLOSSARY.md` terms and ADRs in `docs/adr/` as decisions settle (uses `grilling` + `domain-modeling`).
- `/improve-codebase-architecture`: find deepening opportunities, show them as an HTML report, then grill one (uses `codebase-design`, `grilling`, `domain-modeling`).
- `domain-modeling`, `codebase-design`, `grilling`: shared vocabulary and disciplines the others call; Claude also picks them up on its own.
- `diagnosing-bugs`, `tdd`, `prototype`: debugging loop, red-green-refactor, throwaway prototypes.

Left out: the issue-tracker skills (`to-spec`, `to-tickets`, `triage`, `wayfinder`) that need `/setup-matt-pocock-skills`, and
`code-review`, which would clash with Claude Code's built-in `/code-review`.
